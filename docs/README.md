# Документация проекта SinShell

Добро пожаловать в документацию проекта SinShell! Здесь вы найдете всю необходимую информацию для понимания, разработки и развертывания проекта.

## 📚 Содержание документации

### 1. [PROJECT_SUMMARY.md](./PROJECT_SUMMARY.md)
**Краткое резюме проекта**

Начните отсюда! Этот документ содержит:
- Обзор проекта и ключевые характеристики
- Быструю справку по командам
- Структуру проекта
- Метрики и целевые показатели

**Для кого**: Все участники проекта, новые разработчики

---

### 2. [ARCHITECTURE.md](./ARCHITECTURE.md)
**Детальная архитектура системы**

Глубокое погружение в архитектуру:
- Технологический стек
- Диаграммы архитектуры (Mermaid)
- Структура компонентов
- Потоки данных
- Система команд и тем
- Производительность и безопасность

**Для кого**: Архитекторы, Senior разработчики, Tech Leads

---

### 3. [API.md](./API.md)
**Документация API**

Полное описание REST API:
- Все endpoints с примерами

- Коды ошибок
- Rate limiting
- Примеры использования (curl, JavaScript, TypeScript)
- Postman коллекция

**Для кого**: Backend разработчики, Frontend разработчики, QA

## 🔄 Обновление документации

### Когда обновлять

Документация должна обновляться при:
- Добавлении новых функций
- Изменении API
- Изменении архитектуры
- Обнаружении ошибок в документации

### Как обновлять

1. Создайте feature branch
2. Внесите изменения в соответствующий документ
3. Обновите версию и дату в конце документа
4. Создайте Pull Request
5. Получите review от команды

### Версионирование

Каждый документ содержит в конце:
```markdown
**Версия документа**: X.Y
**Дата обновления**: YYYY-MM-DD
**Автор последних изменений**: Имя
```
